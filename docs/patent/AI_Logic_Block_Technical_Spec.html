[별첨] AI 로직 블록 시스템 기술 설명서

문서 용도: 변리사님 전달용 (발명의 구조 및 동작 원리 설명)
핵심 주제: AI 모델을 일반 투자 전략의 '부품(블록)'처럼 사용할 수 있게 하는 신호 평가 인터페이스
작성일: 2026. 01. 29.

1. 발명의 배경 및 목적

기존의 퀀트 투자 툴은 'RSI가 30 이하일 때'와 같은 단순한 수식 조건만 설정할 수 있었습니다. 사용자가 직접 학습시킨 AI 모델을 사용하려면 복잡한 코딩이 필수적이었습니다.

본 발명은 AI 모델의 복잡한 출력값(확률, 예측 수치 등)을 '매수/매도'라는 단순한 신호로 자동 변환해주는 평가 엔진을 제공하여, AI를 레고 블록처럼 쉽게 조립할 수 있게 하는 시스템입니다.

2. 시스템 구성도 (Structure)

이 시스템은 크게 설정부(User Input), 처리부(Engine), 출력부(Result)로 나뉩니다.

3. 핵심 동작 원리 (Algorithm)

사용자 말씀대로 AI 모델의 종류(분류 vs 회귀)에 따라 내부적으로 완전히 다른 평가 로직이 작동합니다. 시스템은 이를 자동으로 감지하여 적절한 알고리즘을 적용합니다.

3.1. 분류 모델 (Classification) 로직

("위/아래"를 맞추는 모델)

이 모델은 AI가 [상승확률, 하락확률]을 출력하므로, 이를 해석하는 전용 로직이 필요합니다.

  • 최고 확률 모드 (Highest Probability)
    • 로직: argmax(확률벡터)
    • 설명: 상승 확률이 하락 확률보다 높으면 무조건 매수.
  • 임계값 모드 (Probability Threshold)
    • 로직: max(확률) >= 사용자설정값(예: 80%)
    • 설명: "확실할 때만 진입". 아무리 상승 확률이 높아도 79%면 매매하지 않음.

3.2. 회귀 모델 (Regression) 로직

("얼마나 오를지" 가격을 예측하는 모델)

이 모델은 AI가 [예측가격] 또는 [예측수익률]이라는 하나의 숫자를 출력하므로, 다른 해석 방법이 필요합니다.

  • 방향성 모드 (Direction)
    • 로직: sign(예측수익률) == 사용자설정방향
    • 설명: 1%가 오르든 10%가 오르든, 일단 "양수(+)"면 매수.
  • ★ 신뢰도 모드 (Confidence / MC Dropout)
    • 로직: LowerBound > 0 (상승 시)
    • 설명: AI가 예측한 값의 범위(Range)를 봅니다. "최악의 경우에도 0보다 큰가?"를 검증합니다.
      예측값이 +3%라도, 불확실성이 커서 범위가 -1% ~ +7%라면 0 이하로 떨어질 위험이 있으므로 매수하지 않습니다. (손실 방어 핵심 기술)

4. 처리 흐름도 (Flowchart)

평가 엔진은 모델의 타입(Type)을 먼저 체크한 후, 알맞은 경로로 분기(Branching)합니다.

5. 발명의 기술적 특징 (특허 청구 포인트)

  1. 이중 모드 평가 엔진 (Dual-Mode Evaluation Engine)
    • 성격이 전혀 다른 두 가지 AI 모델(분류/회귀)을 하나의 시스템 안에서 통합 처리하는 구조.
    • 사용자는 모델 내부 수학을 몰라도 "임계값"이나 "신뢰도" 같은 직관적인 옵션만 조절하면 됨.
  2. 불확실성 제어 (Uncertainty Control)
    • 회귀 모델의 Confidence 모드는 단순 예측값이 아니라, AI의 "자신감(신뢰도)"을 매매의 안전장치(Safety Lock)로 활용.
